## 公开版本与替换

原维护资料来自私有仓库，本仓库公开。全部文件已经替换真实部署标识：

| 示例值 | 使用前替换为 |
| --- | --- |
| `lab-server` | 你实际使用的 SSH Host 别名 |
| `llmops`、`/home/llmops` | 部署账户、同名用户组及其主目录 |
| Slurm 的 `llmops` 节点与 `llmops-research` 集群 | 实际主机名、节点名、集群名；各配置必须一致 |
| `api.example.org`、`example.org` | 实际 API 域名和 DNS 区域 |
| `prlab-api` | 新 API 使用的独立 Cloudflare Tunnel 名称 |
| `192.0.2.10` | 实际内网地址，仅作说明，不能用于公网 DNS |
| `example-admin` | 示例管理员；成员通过邮箱申请，原六个测试成员已删除 |

此目录是公开示例和历史运行记录，不能直接覆盖现有生产配置。
内存、CPU、GPU 型号、设备编号、版本、分区和权限同样需要按目标服务器核对。
代码与 systemd 单位中的路径是部署到服务器后的路径，不是 Git 工作目录；
不要为了使用这些示例而修改服务器账户、主机名或运行中的 GPU 作业。

凭据、个人邮箱、会话密钥、隧道 token、Munge 密钥、数据库、日志、备份、权重和二进制程序均不迁入公开仓库。
它们原本也不属于旧仓库的跟踪文件，继续通过服务器私密文件及受限备份维护。
公开 Git 资料不能替代生产数据库和密钥备份。

## 迁移时修正

- 根目录新增 `PRLAB.md`，中英文 README 增加入口，不覆盖上游介绍。
- 扫描器及 hook 改为适应嵌套的 `ops/`，可在项目根目录执行：

  ```bash
  python3 ops/scripts/validate.py
  ```

- 如需可选的提交前 hook，先检查已有 `core.hooksPath`，不要覆盖已有检查流程；
  无需保留其他 hooks 时，可设置 `git config core.hooksPath ops/.githooks`。

- New API 验收引用改为本仓库相对链接，审批文档记录后续选择 Mailjet，未声称真实投递成功。

未导入旧仓库的 Git 历史，以免把历史内部配置重新公开；仅导入经过检查的最新跟踪文件。

原仓库删除由所有者另行操作，本次迁移不删除或归档它，也不改动服务器服务。
